VoltUI
What it adds Install GitHub

A clean and modern modular UI.

VoltUI restyles unit frames, party and raid frames, nameplates, bars, bags, maps, tooltips and chat. Then it adds the small things that save you clicks, all set from one settings window. It looks right the moment you log in, and every part can be switched off.

02Install

Three steps, then /volt.

  1. DownloadGet the newest zip from the releases page.
  2. Unzip into AddOnsPut the VoltUI folder in World of Warcraft\_forever_\Interface\AddOns, so that AddOns\VoltUI\VoltUI.toc exists.
  3. Start the gameA brand-new install offers you a starting layout once. Using Baganator? Untick it first, or VoltUI's bags stay off.
